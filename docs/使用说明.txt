百度网盘纯净补丁 —— 使用说明
项目主页：https://github.com/lastbaigeiapi/BaiduNetdisk-Purify

一、安装
1. 先安装一个已支持版本的官方百度网盘客户端。目前支持 8.9.7（8.9.7.101），官方下载地址：
   https://issuepcdn.baidupcs.com/issue/netdisk/yunguanjia/BaiduNetdisk_8.9.7.101.exe
   （百度官网只提供最新版；新版本的支持情况以项目主页为准。）
2. 等上传/下载任务完成后，双击 BaiduNetdisk-Purify-Setup.exe，按提示安装（约 10~40 秒）。
   安装器会按你的百度网盘版本自动获取对应的补丁方案；断网时使用内置方案。
3. 安装向导中有两个可选项（默认都勾选）：
   - 精简组件：移出约 670 MB 与网盘无关的组件（看图、播放器、AI、同步、Office 插件等），卸载时放回；
   - 移除资源管理器集成：去掉右键菜单里的百度网盘项和同步图标。会弹出一次管理员确认，点“否”则只跳过这一项。
4. 安装完成后正常打开百度网盘即可（从开始菜单或桌面图标打开，不要“以管理员身份运行”）。

二、使用上的变化
- 双击文件：先下载到本地，下载完成后用系统默认程序打开；已下载过的文件直接打开。
  程序、脚本、压缩包等不会被自动运行，只会在文件夹中定位。
- 回收站、隐藏空间（保险箱）、自动备份、同步空间等入口已去掉。删除的文件仍在网盘回收站里，可在网页版 pan.baidu.com 找回。

三、卸载 / 还原
设置 → 应用 → 已安装的应用 → 找到“百度网盘纯净补丁（去广告/去营销）”→ 卸载。
卸载会把百度网盘完整还原为官方原版（包括自动更新、移出的组件和资源管理器集成；后者会再弹出一次管理员确认）。

四、常见问题
- 提示“暂时还没有适配你的版本”：这个版本还没有补丁方案，安装程序没有改动任何文件。
- 提示“方案校验失败”：下载到的方案不完整或被改动过，安装程序已中止且没有改动任何文件，请重试。
- 提示“没有写入权限”：百度网盘装在了 Program Files 等目录，右键安装程序“以管理员身份运行”。
- 一直显示“应用程序被修改，请重新安装”的提示框：通常是百度网盘被“以管理员身份运行”了，正常方式打开即可。
  不要点提示框里的“确定”，那会退出百度网盘。
- 打开后要求重新登录：这是百度网盘自身的登录状态失效，正常登录即可，与补丁无关。
- 想升级百度网盘：先卸载本补丁，再升级百度网盘，然后重新运行安装程序（新版本需要已有对应方案）。
- 日志：%LOCALAPPDATA%\BaiduNetdiskPurify-install.log（安装）、%APPDATA%\baidunetdisk\nd_hide_notice.log（提示隐藏）
