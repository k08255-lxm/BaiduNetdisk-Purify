百度网盘纯净补丁 —— 使用说明
项目主页 https://github.com/lastbaigeiapi/BaiduNetdisk-Purify
下载安装器 https://github.com/lastbaigeiapi/BaiduNetdisk-Purify/releases/latest/download/BaiduNetdisk-Purify-Setup.exe

一、支持的版本
当前支持 Windows 版百度网盘的 9 个构建。官方安装包链接及 SHA-256 见项目主页的支持表。
- 8.10.3.103（仅官方 x64 安装包）、8.9.7.101、8.9.2.101、8.8.8.101、8.8.6.102、8.8.3.101、8.7.9.102、8.6.8.102、8.5.9.102。
- 从 v1.3.0 起，所有版本安装或重装补丁时均需访问 raw.githubusercontent.com，以在线获取对应方案。

二、安装
1. 先安装支持表中对应的官方客户端，核对安装包版本和 SHA-256。
2. 等上传、下载任务完成后，运行最新版 BaiduNetdisk-Purify-Setup.exe。
   安装器按原始 core.asar 的 SHA-256 匹配方案，并校验方案索引签名及文件哈希。
   免安装版或未登记安装位置的客户端，可先正常打开百度网盘，让安装器通过正在运行的进程查找路径。
3. 安装向导中有两个可选项（默认都勾选）：
   - 精简组件：移出看图、播放器、AI、同步和 Office 插件等组件，卸载时放回。8.9.7.101 实测约 670 MB，体积随版本而异。
   - 移除资源管理器集成：去掉右键菜单里的百度网盘项和同步图标。会弹出一次管理员确认，点“否”则只跳过这一项。
4. 安装完成后正常打开百度网盘即可（从开始菜单或桌面图标打开，不要“以管理员身份运行”）。

三、使用上的变化
- 双击文件：先下载到本地，下载完成后用系统默认程序打开；已下载过的文件直接打开。
  程序、脚本、压缩包等不会被自动运行，只会在文件夹中定位。
- 回收站、隐藏空间（保险箱）、自动备份、同步空间等入口已去掉。删除的文件仍在网盘回收站里，可在网页版 pan.baidu.com 找回。

四、卸载与还原
设置 → 应用 → 已安装的应用 → 找到“百度网盘纯净补丁（去广告/去营销）”→ 卸载。
卸载会把百度网盘完整还原为官方原版（包括自动更新、移出的组件和资源管理器集成；后者会再弹出一次管理员确认）。
卸载使用本机备份，可断网操作。

五、常见问题
- 提示“无法从 GitHub 下载补丁方案”时，请确认当前网络能访问 raw.githubusercontent.com 后重试。下载失败时客户端文件保持原样。
- 匹配不到方案时，请核对官方安装包的 SHA-256。安装器会在获取并校验有效方案后才修改客户端。
- 提示“方案校验失败”：下载到的方案不完整或被改动过，安装程序已中止且没有改动任何文件，请重试。
- 提示“没有写入权限”：百度网盘装在了 Program Files 等目录，右键安装程序“以管理员身份运行”。
- 一直显示“应用程序被修改，请重新安装”的提示框：通常是百度网盘被“以管理员身份运行”了，正常方式打开即可。
  不要点提示框里的“确定”，那会退出百度网盘。
- 从 8.9.7.101 降到支持表中更早的版本时，官方原版和补丁版都可能要求重新登录。按百度网盘提示登录即可。
- 想升级百度网盘：先卸载本补丁，再升级百度网盘，然后重新运行安装程序（新版本需要已有对应方案）。
- 日志：%LOCALAPPDATA%\BaiduNetdiskPurify-install.log（安装）、%APPDATA%\baidunetdisk\nd_hide_notice.log（提示隐藏）
