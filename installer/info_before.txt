百度网盘纯净补丁（去广告 / 去营销 / 精简）—— 安装须知

【这是什么】
本程序不是百度网盘本体，也不包含百度网盘的任何程序文件。
它只会在你电脑上已经安装好的“正版百度网盘”上打补丁，把客户端精简成一个纯粹的网盘工具：浏览、上传、下载、分享与转存。

【使用前提】
1. 先安装官方百度网盘客户端；
2. 安装器按原始 core.asar 的 SHA-256 从 GitHub 匹配补丁方案，验证索引签名及方案文件哈希。
   GitHub 无法访问时，只有随包内置了对应方案的客户端可以离线打补丁。
   项目主页列出了支持版本、官方安装包和 SHA-256。8.10.3.103 仅适配官方 x64 安装包。
   https://github.com/lastbaigeiapi/BaiduNetdisk-Purify

【会去掉什么】
- 广告与推广：顶栏/侧栏/右下角广告、活动弹窗、福利任务、会员推销与续费引导、游戏中心、金币、热词推送、“下载手机客户端”入口
- 头像卡片：只保留昵称、会员到期时间、帮助中心、切换账号（去掉 AI 点数、权益卡片、立即续费）
- 办公套件与 AI：新建笔记/AI PPT、格式转换、文字提取、转文字、导入在线文档、AI 剪辑/总结/修图、云打印、库库AI（含后台预加载）、知识库、搜索栏 AI 工具、AI 下载任务
- 非核心功能入口：同步空间、消息、工具、回收站、隐藏空间（保险箱）、自动备份、文档历史版本、文件快传、用手机打开
- 在线预览：双击文件改为“下载后用系统默认程序打开”（图片/视频/音乐/文档等；程序、脚本、压缩包只会在文件夹中定位，不会自动运行）
- 托盘菜单：去掉版本升级、一键反馈、同步与回收站相关项
- 设置：去掉与网盘无关的选项

【会保留什么】
浏览网盘、上传、下载、分享（链接/取消分享）、转存和订阅、云添加（链接/BT）、新建文件夹、重命名/复制/移动/删除、快捷访问。
删除的文件仍进入网盘回收站，需要找回时请使用网页版 pan.baidu.com。
会员权益、下载速度由百度服务器决定，本补丁不做任何改动。

【可选项（下一页勾选）】
- 精简组件。把看图、播放器、AI 引擎、语音、同步引擎和 Office 插件等移到 nd_purify\removed。8.9.7.101 实测约 670 MB，卸载时原样放回。
- 移除资源管理器集成：去掉文件右键菜单里的百度网盘项和同步覆盖图标。需要管理员权限，安装时会弹出一次系统确认；
  选择“否”则跳过此项，其余部分照常安装。重新登录 Windows 后完全生效。

【安装时会发生】
- 自动关闭正在运行的百度网盘，请先等待上传/下载任务完成；
- 原始文件自动备份；关闭百度网盘的自动更新（避免补丁被覆盖）；
- 百度网盘自带的完整性检查会弹出“应用程序被修改”的提示，本补丁会在后台自动将其隐藏（网盘可正常使用）。
  注意：请不要“以管理员身份运行”百度网盘，否则 Windows 不允许后台程序隐藏这个提示。

【如何还原】
在“设置 → 应用 → 已安装的应用”中卸载“百度网盘纯净补丁”，即可把百度网盘完全还原为官方原版
（移出的组件放回原处；若移除过资源管理器集成，卸载时会再弹出一次管理员确认以恢复）。
